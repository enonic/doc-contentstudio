= Navigator
:toc: right
:imagesdir: images

The *Navigator* is the default menu item in Content Studio — what you see when you open the application. It is built around the current project's content list and the actions you can perform on it.

The action toolbar runs across the top. Below it, the <<#content_list,Content list>> is the primary panel. The <<#search_panel,Search panel>> opens to its left, while the <<preview#,Preview panel>> and <<contextpanel#,Context panel>> appear to its right. The layout adapts to the available width, so fewer panels and columns may be visible in a narrow window.

[[toolbar]]
== Toolbar

image::navigator-toolbar.png[Navigator toolbar showing search icon, buttons new edit delete duplicate move sort preview and the main workflow action button with dropdown, 961px]

The toolbar contains the following content actions. Buttons are enabled or disabled according to the selection and the current user's permissions:

* *New* — opens the <<../actions/new#,New content>> dialog.
* *Edit* — opens the selected content for <<../actions/edit#,editing>> in a new browser tab.
* *Delete* — opens the <<../actions/delete#,Delete>> dialog. Deleted items are moved to the <<archive#,Archive>>.
* *Duplicate* — makes a <<../actions/duplicate#,copy>> of the selected content.
* *Move* — opens the <<../actions/move#,Move item(s) with children>> dialog.
* *Sort* — opens the <<../actions/sort#,Sort items>> dialog for ordering the selected item's children.
* *Preview* — opens renderable content in a new browser tab; see the <<../actions/preview#,Preview action>>.

The action button on the right is context-dependent. Its main action and dropdown options vary with the selection, content status, workflow state, and current user's permissions. Typical actions include:

image::navigator-workflow-menu.png[Toolbar, 181px]

* *Publish* — opens the <<../actions/publish#publishing_wizard,Publishing wizard>> for content that is not online.
* *Mark as ready* — changes selected in-progress content to the <<../workflow#_ready_for_publishing,ready for publishing>> workflow state.
* *Publish Tree* — opens the <<../actions/publish#publish_tree,Publishing wizard>> with the selected content, its descendants, and their dependencies.
* *Unpublish* — opens the <<../actions/unpublish#,Unpublish wizard>> for content that is online.
* *Request Publishing* — opens the <<../workflow/issues#publish_requests,Publish Request>> wizard when the current user cannot publish the selected content.
* *Create Task* — opens the <<../workflow/issues#create_a_task,New Task>> dialog. It is available without a content selection; selected items are attached to the new task automatically.

Applicable actions are also available from the context menu that appears when you right-click a content item in the list.


[[content_list]]
== Content list


The main panel displays the content list for the current project.

By default, it shows the items in their native tree structure, with the root content at the top and children nested beneath their parents. Items with children will have an expand icon to the left, which can be clicked to expand or collapse that structure.

image::navigator-list.png[The default content listing including tree structure and online state column, 772px]


The content list has its own toolbar with an icon to refresh the list and a checkbox to select or deselect all displayed items.

Double-click a content item to open it for <<../editor#,editing>> in a new browser tab, or right-click a content item to open its context menu.

=== Columns

The content list contains two main columns. Columns may be hidden as the panel narrows:

* Column 1 contains the content type icon, display name, and path. An expand icon appears when the content has children. Additionally, a workflow state icon may appear on top of the content icon, indicating invalid, in progress or ready.

* Column 2 shows the <<../workflow#publish_state,publish state>> as text: *Online*, *Offline*, *Scheduled*, or *Expired*, telling you whether the content is currently published, unpublished or not.

NOTE: If you are working in a layer, a third column will appear, showing the content's layering status. It will indicate if it is an original item, inherited from the parent project, or inherited and localized. See <<../projects/layers#,layering>> for details.

=== Bulk selection

Use the checkboxes to select one or multiple items. Applicable toolbar and context-menu actions then operate on the complete selection; actions that require a single item are disabled.

image::navigator-bulk.png[Bulk selection mode demonstrated along with right click for context menu, 771px]



[[search_panel]]
== Search

Open the search panel with the 🔍 (magnifying glass) button on the toolbars left hand side to open the search panel.

Use the Free-text search to find content by content, content ID, or path.


image::navigator-search.png[Search panel with a text query and content type filter, matching content list, and selected-item preview, 1440px]

The hit count appears below the search field. Click *Clear* to reset all search terms and filters.

Results update in the content list as search terms and filters change. Children of matching content items are also included, but remain hidden until their parent is expanded.


=== Filtering

In addition to free text, the search panel provides the following faceting filters, to help you drill down to the content you want:

* Content type
* Last modification date
* Last modified by
* Owner
* Language

Each content type with at least one match appears in the *Content type* filter, with the number of matches in parentheses. Select one or more content types to limit the results. By default, the five most common matching types are shown; click *Show more* to display the complete list.

=== Search report

Use the *Export* button next to the hit count to download the search result as CSV. The export contains basic metadata such as ID, display name, and path, but not custom fields from the content type.


== Preview and Context panels

Selecting a single content item updates both right-hand panels:

* The <<preview#,Preview panel>> shows the selected item's draft rendition. Its toolbar displays status and offers preview modes and device-size emulation. If the item cannot be rendered, the preview is unavailable or replaced by a placeholder.
* The <<contextpanel#,Context panel>> hosts widgets for the selected item. Built-in widgets provide details, dependencies, and version history; installed applications may contribute additional widgets.

Both panels are also used in the <<../editor#,Editor>>. Their dedicated pages describe all controls and available modes.
