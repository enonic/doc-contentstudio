= Juke AI
:toc: right
:imagesdir: ai/images
:experimental:

Juke AI assists editors with writing and translating content in the <<editor#,Content Editor>>. It provides two skills:

* *<<#content_operator,Content Operator>>* — a chat interface for generating, revising, and comparing suggestions for form fields.
* *<<#ai_translator,AI Translator>>* — translates supported text when localizing content or changing its language.

NOTE: *Content Studio+ feature.* Juke AI requires a valid https://market.enonic.com/vendors/enonic/content-studio-plus[Content Studio+] subscription and the application for each skill that editors will use.

Review generated and translated values before saving or publishing. AI suggestions can contain mistakes, and inserting them does not replace the normal <<workflow#,content workflow>>.

[[content_operator]]
== Content Operator

The https://market.enonic.com/vendors/enonic/ai-content-operator[Juke AI Content Operator] application provides the chat interface. It works with the current content's form and returns suggestions that can be inserted into individual fields.

[[_interface]]
=== Open the chat

Click the Juke icon in the Content Editor toolbar to open or close the chat.

.The Juke icon in the Content Editor toolbar
image::ai-icon.png["Content Editor toolbar with an annotation pointing to the Juke AI icon", 490px]

Enter a prompt at the bottom of the dialog and use the send arrow to submit it. Juke's responses appear in the conversation, where you can ask follow-up questions or refine the instructions.

.The chat dialog with a prompt, response, and Retry control
image::ai-chat.png["Juke AI chat showing the New chat icon, conversation, response copy control, Retry button, and prompt field", 690px]

Use *New chat*, the icon in the upper-left corner, to clear the conversation and its field context. Starting a new chat does not undo values already inserted into the form.

[[_mentions]]
=== Field mentions

Type `@` in the prompt to open the field picker, then select a field. This inserts a *field mention*: a reference to that form field and its value. You can mention several fields in the same prompt, for example to generate a display name from the body text or revise a title and teaser together.

.Choosing a field to mention in the prompt
image::ai-mention.png["Typing @ opens the field picker with All Inputs, Display Name, Teaser text, and Body text", 1175px]

The *All Inputs* choice references all available fields in the current scope. A field mention appears as a labeled token in the prompt; select it from the picker so Juke receives the field reference.

Example prompts using field mentions:

* Improve `@Display Name` and `@Teaser text`.
* Write a shorter `@Teaser text` based on `@Body text`.
* Turn the list in `@Body text` into a numbered list.

=== Field context

Field context narrows the conversation to a particular part of the form. The selected field's label appears above the prompt, such as *Body text*. When a field context is active, the mention picker offers fields within that scope. Use *Clear context* beside the field label to return to the form's root-level fields.

.The selected Body text field shown as the chat context
image::ai-field-context.png["Selected Body text field beside the Juke AI prompt showing Body text as the active context and the Clear context control", 1020px]

Field mentions let you identify the inputs to use in an individual prompt. The available fields depend on the current form and context; see <<#known_issues,Scope and limitations>>.

[[_insert]]
=== Suggestions and insertion

Juke can return a general response or suggestions associated with named fields. Field suggestions show the target field's label above the proposed value.

.Suggestions for two mentioned fields
image::ai-suggestions.png["Juke suggestions for Display Name and Teaser text with field mentions, per-field controls, Insert All, and Retry", 865px]

Each field suggestion provides these controls:

* *Insert* — the sparkle icon replaces the corresponding form value with the suggestion.
* *Copy* — the overlapping-squares icon copies the suggestion to the clipboard for manual use.

Use btn:[Insert All] to insert the response's field suggestions together. A general response can be copied, but has no target field for insertion.

Inserted values update the open form. Review them and use the normal <<actions/edit#save,Save>> and <<actions/publish#,publishing actions>> to keep or publish the changes.

=== Retry

Use btn:[Retry] beneath the latest response to generate another response to the same prompt. To change the instructions, send a follow-up prompt instead. A new response does not replace form values until you insert it.

[[_variants]]
=== Alternatives

Ask for multiple alternatives when you want to compare suggestions for a field, for example: `Make 3 alternatives for @Teaser text`.

Use the arrows beside the field label to browse the alternatives. The counter, such as *1/3*, identifies the currently selected suggestion. *Insert* uses that suggestion; btn:[Insert All] uses the selected alternative for each field in the response.

.Browsing three alternatives for a teaser
image::ai-variants.png["Teaser text suggestion with previous and next arrows, a 1/3 counter, Copy, Insert, Insert All, and Retry", 640px]

These alternatives exist in the chat. They do not create content copies or <<contextpanel/variants#,content variants>>.

=== General instructions

Configure *General Instructions* on the Content Operator application to give Juke guidance that applies across conversations. This can describe the intended audience, tone of voice, preferred terminology, or writing style. Editors can give more specific instructions in individual prompts.

.General instructions for the Content Operator
image::ai-instructions.png["Juke AI Content Operator application configuration with General Instructions for tone and writing style", 760px]

Add and configure the application in the relevant <<projects#project-applications,project>> or <<content-types/site#_site_applications,Site>> application settings. Project application settings apply to content outside Sites; configure the application on a Site for content within it. Changing these settings requires the <<projects#project-roles,Owner>> project role or an administrator role.

[[known_issues]]
=== Scope and limitations

The Content Operator works in the Content Editor with the display name and supported text fields, including TextLine, TextArea, and HtmlArea inputs. Use the field picker to see which fields are available in the current context.

The chat currently does not support fields in mixins or pages. Support for these fields is planned for an upcoming release.

Suggestions are intended for content authoring. They do not perform content actions such as publishing, moving, or deleting items. The <<#ai_translator,AI Translator>> has its own dialog and is not invoked through the Content Operator chat.

[[ai_translator]]
== AI Translator

The https://market.enonic.com/vendors/enonic/juke-ai-content-translator[Juke AI Content Translator] application translates content into the item's target language. When enabled, it opens the *AI Automated Translation* dialog after an editor <<actions/localize#localize,localizes an inherited item>> or changes an item's language.

=== Translate content

The dialog identifies the target language and automatically copies the Translator application's *General Instructions* into *Translation instructions*. Use this standard prompt as provided, or adjust it for the current item before clicking btn:[Translate]. Instructions can specify terminology, tone, words to avoid, or names and phrases that must remain unchanged.

.Translation into the layer's language with instructions for the current item
image::ai-translation.png["AI Automated Translation dialog targeting Norwegian, with Translation instructions and a Translate button", 790px]

Translation progress is reported for each value, and successful results are inserted into the open form. Close the dialog when translation finishes, review the results, and save the content. Publishing remains a separate action; see <<actions/publish#,Publish>>.

The Translator handles the display name and supported text inputs, including TextLine, TextArea, and HtmlArea fields. Text in supported X-data and page components can also be translated when their schemas are available. Non-text values and unsupported inputs are left unchanged.

NOTE: The Localize action stops the item's *Content* inheritance before the Translator opens. Translation does not change name, parent, or sort inheritance. See <<projects/layering#content_inheritance,Content inheritance>>.

=== Translation instructions

Configure *General Instructions* on the Translator application to provide reusable translation guidance, such as a glossary or language-specific writing conventions. The Translator has its own instructions, separate from the Content Operator's.

.General translation instructions on the Translator application
image::ai-translator-prompt.png["Juke AI Translator application configuration with a General Instructions field and Apply button", 760px]

Configure the application at the relevant <<projects#project-applications,project>> or <<content-types/site#_site_applications,Site>> scope. Changing application settings requires the <<projects#project-roles,Owner>> project role or an administrator role.

These instructions are automatically copied into the translation dialog for each item. Editors can use the standard prompt unchanged or adjust *Translation instructions* for that item. Edits in the dialog do not change the application's configured instructions.
