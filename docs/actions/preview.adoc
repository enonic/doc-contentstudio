= Preview
:toc: right
:experimental:

The *Preview* action opens the current content preview in a separate browser tab.

NOTE: The new tab uses the preview mode selected in the <<../workbench/preview#,Preview panel>>. For example, selecting *JSON* opens the JSON preview. See <<../workbench/preview#preview_modes,Preview modes>> for the available choices.

== Opening a preview

Choose btn:[Preview] from the <<../workbench/navigator#,Navigator>> or <<../editor#,Content Editor>> toolbar, or *Preview* from an item's right-click menu in the Navigator.

The keyboard shortcut is `Alt + Space` on macOS or `Ctrl + Alt + Space` on Windows/Linux. See <<../keyboard-shortcuts#,Keyboard shortcuts>> for the full reference.

The new tab shows draft content with the full browser viewport available. Opening a preview does not publish the content.
