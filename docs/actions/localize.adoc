= Localize
:toc: right
:experimental:

The *Localize* action enables editing of inherited content data in the current <<../projects/layering#,layer>>. It stops the item's content data from following changes in the parent layer, so editors can adapt it locally.

== Availability

Localize is available inside the <<../editor#,Content Editor>> for an item whose content data is still inherited. Use <<edit#,Edit>> to open the item first. Its form is initially read-only, and opening it does not change its inheritance.

Click btn:[Localize] in the editor toolbar to enable the form. The action applies to the item open in that editor tab and requires permission to edit it in the current layer. See <<../workbench/permissions#,Permissions>> for content access controls.

Items created directly in the current layer, and items whose content data is already localized, can be edited without this action.

== Effect on the item

The item keeps its existing content values as the starting point for local editing. Subsequent parent changes to its content data no longer replace those values. Local edits affect the current layer's item; they do not edit the parent item.

Localize also assigns the layer's default language. Other inheritance dimensions remain unchanged. See <<../projects/layering#localize,Localization and inheritance>> for the full effects on content, name, location, and sort order.

When the <<../ai#ai_translator,AI Translator>> is enabled, its translation dialog opens after localization. Review any translated values before saving or publishing.

== Editing after localization

Use the <<../editor/content-form#,Content Form>> to edit the localized values and <<../editor#_saving_and_validation,Save>> to store changes. Localization does not publish the item; publishing is managed independently in each layer through the normal <<../workflow#,workflow>>.

To replace local adaptations with the parent's current values and restore inheritance, use <<reset#,Reset>> in the Content Editor. Review that action's effects before using it.
