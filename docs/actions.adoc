= Actions
:toc: right

Content actions create, edit, organize, and publish content. This page summarizes the available actions and links to their detailed references, with related actions grouped on shared pages and task and request actions covered under Issues.

== Access and availability

Actions are available from the toolbars and their menus in the <<workbench/navigator#,Navigator>> and <<editor#,Content Editor>>. Right-clicking an item in the Navigator opens a context menu with applicable actions. Some actions also have <<keyboard-shortcuts#,keyboard shortcuts>>.

The available actions depend on where you are working, the selected content, its <<workflow#,workflow and publish state>>, and your <<workbench/permissions#,permissions>>. An action may be hidden or disabled when it does not apply. For example, *Unpublish* applies to online content, while *Localize* applies to inherited content in a layer.

In the Navigator, actions that support multiple items operate on the selection; actions that require a single item are disabled when several are selected. In the Content Editor, actions apply to the item open in that tab. Some actions are available without a selection, such as *New* and *Create issue*.

The primary workflow button changes with the content and your permissions, offering actions such as *Mark as ready*, *Publish*, or *Request publishing*. Its menu provides additional workflow and issue actions.

== Available actions

Related actions share a page; the links below open the relevant action or section. Each reference explains the action's controls, restrictions, and effects, including how it handles children and dependencies.

[cols="1,3", options="header"]
|===
|Action |Purpose

|<<actions/new#,New>>
|Create content by choosing a content type or uploading files.

|<<actions/edit#edit,Edit>>
|Open selected content in the Content Editor.

|<<actions/edit#save,Save>>
|Store changes to the current item's draft without publishing them.

|<<actions/duplicate#,Duplicate>>
|Create a copy of selected content.

|<<actions/move#,Move>>
|Move content to a different parent in the content tree.

|<<actions/sort#,Sort>>
|Set the order of an item's children.

|<<actions/preview#,Preview>>
|Open the content in a new browser tab using the selected preview mode.

|<<actions/publish#mark_as_ready,Mark as ready>>
|Mark valid content as ready for publishing.

|<<actions/publish#publish,Publish>>
|Make draft content available online immediately or through scheduled publishing.

|<<actions/publish#publish_tree,Publish tree>>
|Open the Publishing wizard with the selection, its descendants, and their dependencies.

|<<actions/unpublish#,Unpublish>>
|Take published content offline.

|<<workflow/issues#publish_requests,Request publishing>>
|Ask another user to review and publish content.

|<<workflow/issues#create_a_task,Create issue>>
|Create an editorial work item with assignees and optional content attachments.

|<<actions/localize#localize,Localize>>
|Stop inheriting content data so it can be edited in the current layer.

|<<actions/localize#reset,Reset>>
|Replace local values with the parent's values and restore inheritance.

|<<actions/delete#delete,Delete>>
|Move content from the active tree to the Archive.

|<<actions/delete#restore,Restore>>
|Return archived content to the active tree.

|<<actions/delete#_permanent_deletion,Permanent deletion>>
|Use *Delete* in the Archive to remove archived content permanently.
|===
